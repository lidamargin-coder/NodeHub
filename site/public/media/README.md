# 📁 Папка медиафайлов для сайта NodeHub (`site/public/media`)

Положи сюда свои скриншоты, видео или фоны — сайт автоматически подхватит их при наличии!

---

### Поддерживаемые файлы:

1. **`hero_preview.png`** или **`hero_preview.jpg`**
   - Главный скриншот программы в центральной витрине Hero-секции.
   - Если файла нет — сайт отображает интерактивный векторный макет интерфейса NodeHub с карточками и кнопками.

2. **`hero_video.mp4`**
   - Видео работы лаунчера (скринкаст процесса установки мода или обзора интерфейса).
   - Если положить этот файл — в центральной рамке автоматически включится плавный зацикленный видеоплеер без звука с кнопкой паузы.

3. **`custom_bg.jpg`** или **`custom_bg.png`**
   - Фоновое изображение для сайта (накладывается поверх зелёного WebGL-градиента с мягким затемнением).

4. **Скриншоты отдельных разделов** (для карточек возможностей):
   - **`screenshot_catalog.png`** — каталог модов STMods и поиск.
   - **`screenshot_details.png`** — панель описания, карусель фото и кнопка установки.
   - **`screenshot_installed.png`** — вкладка «Установленные» и управление модами.

---

### Примечание:
Все пути в коде сайта настроены на `/media/<имя_файла>`. Перезагружать сервер не нужно — Vite сразу отобразит добавленные файлы!
